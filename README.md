# NHANES Mortality Prediction

A machine learning pipeline for individual-level mortality prediction using the National Health and Nutrition Examination Survey (NHANES), linked to the National Death Index.

## Overview

This project trains five conditional annual XGBoost models on 56,000+ NHANES participants across 10 survey cycles (1999–2018) to predict the probability of death in each of years 1 through 5 post-exam. These annual predictions compose into multi-year survival estimates and individual mortality tables using an actuarial select-and-ultimate framework.

### Key Results

| Metric | Value |
|--------|-------|
| Annual model AUC-ROC | 0.852 – 0.884 |
| Annual calibration (sum pred / sum deaths) | 0.927 – 1.062 |
| Composed 5-year calibration | 0.925 |
| Predictors | 23 features across 6 domains |
| Relativity decay rate | 0.90/year (10% convergence) |

## How It Works

1. **Annual Models**: Five XGBoost classifiers predict conditional mortality (q<sub>x</sub>) for years 1–5 post-exam. Each model trains only on individuals who survived prior years, giving true actuarial q<sub>x</sub> values.

2. **Multi-Year Survival**: Annual predictions compose via S(t) = (1−q₁)(1−q₂)···(1−q_t) to produce calibrated multi-year survival estimates.

3. **Population Relativity**: Individual q<sub>x</sub> is compared to CDC population life tables to derive mortality relativities. Analysis shows relativities converge toward population normal at ~10%/year.

4. **Projection**: Beyond the 5-year observation window, relativities are graded back to population mortality using the empirically observed decay rate, enabling full life table construction.

Run everything end to end:

```
python "03 code/00_run_all.py"
```

Or run individual steps:

| # | Script | Purpose |
|---|--------|---------|
| 00 | `run_all.py` | Master runner — executes all steps below |
| 01 | `download_raw_files.py` | Download 100 raw NHANES files from CDC |
| 02 | `process_and_combine.py` | Combine into single harmonized CSV |
| 03 | `preprocess_annual.py` | Create conditional annual outcomes + features |
| 04 | `baseline_gam_annual.py` | Fit GAM baselines by age/gender/year |
| 05 | `train_annual_models.py` | Train 5 XGBoost models |
| 06 | `predict_annual.py` | Score all individuals |
| 07 | `compose_multiyear_survival.py` | Chain annual qx into multi-year survival |
| 08 | `download_cdc_life_table.py` | Download CDC 2021 period life table |
| 09 | `fit_relativity_splines.py` | Analyze relativity convergence patterns |
| 10 | `project_and_grade.py` | Extrapolate relativities beyond year 5 |
| 11 | `mortality_table_builder.py` | Library: build individual mortality tables |
| 12 | `analysis_and_charts.py` | Validation charts and summaries |

## Data Sources

- **NHANES**: [CDC NHANES](https://www.cdc.gov/nchs/nhanes/index.htm) — 10 survey cycles, downloaded automatically by script 01
- **Linked Mortality**: [CDC NDI Linkage](https://www.cdc.gov/nchs/data-linkage/mortality-public.htm) — follow-up through Dec 31, 2019
- **CDC Life Table**: [NVSS Vol. 72 No. 12](https://www.cdc.gov/nchs/data/nvsr/nvsr72/nvsr72-12.pdf) — U.S. 2021 period life table

All data is public-use and downloaded automatically by the pipeline. No manual downloads required.

## Features Used

| Domain | Variables |
|--------|-----------|
| Demographics | Age, sex, race/ethnicity, education, income-to-poverty ratio |

## Using the Mortality Table Builder

```python
import sys
sys.path.insert(0, "03 code")
from importlib.util import spec_from_file_location, module_from_spec
spec = spec_from_file_location("builder", "03 code/11_mortality_table_builder.py")
mod = module_from_spec(spec); spec.loader.exec_module(mod)

import pandas as pd
cdc = pd.read_csv("02 processed data/cdc_life_table.csv")

table = mod.build_mortality_table(
    age=55, sex="Male",
    annual_qx={1: 0.015, 2: 0.018, 3: 0.020, 4: 0.022, 5: 0.025},
    rel_yr5=1.8, decay_rate=0.90,
    cdc_life_table=cdc, max_age=100
)
print(table[["attained_age", "qx_adj", "lx", "ex"]].head(10))
```
